      Sessions

      How long users stay logged in after a new login. Changing these values applies to new logins only; existing sessions keep their current expiry.

      Registration

      When enabled, the login page links to /register (Sign up). New accounts need username, email, and a password that meets the password policy. Accounts are active immediately (no admin approval yet).

      Force 2FA

      Force every user to enroll TOTP before using Filehub. Can also be set with env FORCE_2FA_ALL=true (env always on if set).

      Password policy

      Applies when creating users, resetting passwords, or users changing their own password. Tightening rules bumps a policy version so existing users must change password on next login.

      Email (SMTP)

      Used for forgot-password reset links. SMTP password is stored in settings and never shown again; leave blank to keep the current password. Env SMTP_* / PUBLIC_BASE_URL override UI when set.

      System

      File storage root and listen address are set via server environment variables (see README).

      • Homes: DATA_ROOT/homes/<user>
      • Shares: paths under DATA_ROOT
      • Quota applies to each user’s home only
